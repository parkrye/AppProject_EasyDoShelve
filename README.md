# EasyDoShelve

무료 공개 웹소설을 TXT로 받아 한국어로 번역해 두고, 원문과 번역을 문단별로 나란히 읽는 안드로이드 앱. 페이지를 보며 "쓸 텍스트 · 따라갈 링크"를 고르면 규칙으로 저장해 같은 사이트에 다시 씀. 하멜른(`syosetu.org`) 규칙 내장.

## 기능

| 탭 | 내용 |
|---|---|
| 홈 | 주소 입력 → 맞는 규칙으로 받기(없으면 규칙 만들기), 다운로드 목록 · 취소, 규칙 목록 · 수정 · 삭제 |
| 서재 | 받은 소설 · 화 목록, 화 보기(원문 문단 위 · 번역 아래), 다시 번역, 삭제 |
| 사전 | 고유명사 등 고정 번역. 화 보기에서 소제목 · 문단을 길게 눌러 단어 추가 |
| 설정 | 다운로드 폴더, 와이파이만, 번역 · 구글 웹 번역, 백업 · 복원 |

- 저장: 고른 폴더 안 `소설 제목/소설 제목.txt` · `소설 제목 (번역).txt`. 다시 받으면 새 화만 이어 씀
- 앱을 닫아도 백그라운드에서 받기 계속(알림 표시). 와이파이만이면 끊길 때 멈추고 연결되면 이어 받음
- 번역: 구글 웹 번역 기본, 실패 시 기기 내 번역(ML Kit, 품질 낮음)

## 설치

[Releases](../../releases)에서 `EasyDoShelve-<버전>.apk`를 받아 설치. Android 8.0 이상, 64비트 · 32비트 ARM 기기.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 서재 · 규칙 · 사전 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `b6e8f043f50b1cc026b8351fa9121f3348fac26fb099ddcf8635bde6ab3184cd`
  (`apksigner verify --print-certs EasyDoShelve-<버전>.apk`로 확인)

## 개인정보 · 네트워크

웹소설을 받는 앱이라 **인터넷을 씀**. 계정 · 광고 · 앱 자체 통계 · 오류 보고 없음.

| 연결 대상 | 보내는 것 | 언제 |
|---|---|---|
| 입력한 소설 사이트 | 일반 브라우저와 같은 페이지 요청 | 규칙 만들기 · 받기 |
| 구글 번역 | 번역할 원문 텍스트 | 번역 · 구글 웹 번역 켜짐(기본) |
| 구글 ML Kit | 번역 모델 다운로드(처음 한 번), ML Kit 사용 통계 | 웹 번역이 꺼졌거나 실패할 때 |

- 받은 파일 · 규칙 · 사전은 기기 안에만 저장. Android 클라우드 백업 끔, 앱 안 백업 · 복원 제공
- 광고 · 추적 도메인 요청 차단

## 이용 시 주의

- 사이트 이용 약관과 저작권을 지켜 개인 감상 용도로만 사용
- 요청 간격 3초 이상. 사이트가 거부하면 간격을 늘리고, 계속되면 중지
